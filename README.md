# Pancas : versions

Ce dépôt ne contient que la dernière version de Pancas (Windows et Android), pour l'installer sur un autre appareil et pour la mise à jour automatique. Le code de Pancas n'est pas ici.

## Télécharger

**[Pancas-0.1.2-installation.exe](https://github.com/marparis/pancas-versions/raw/main/Pancas-0.1.2-installation.exe)** : Windows, version 0.1.2 du 2026-11-17 (9,4 Mo).

Installation pour l'utilisateur seul, sans droits d'administrateur. L'installeur n'est pas signé par Microsoft : si Windows affiche « Windows a protégé votre ordinateur », choisir « Informations complémentaires » puis « Exécuter quand même ».

**[Pancas-0.1.2-android.apk](https://github.com/marparis/pancas-versions/raw/main/Pancas-0.1.2-android.apk)** : Android, version 0.1.2 (15,8 Mo). Android demande d'autoriser l'installation depuis le navigateur ou les fichiers, puis de confirmer.

## Nouveautés

Pancas arrive sur Android (tablette et téléphone) : fiches, chronologie, relations, cartes en consultation et écriture, sur le coffre qu'Obsidian tient à jour. Sur le PC : le message de l'écran des mondes est retiré, l'indexation d'un petit monde ne reste plus bloquée, et le champ d'idée de l'accueil garde la main quand une fiche change ailleurs.

## Mises à jour

Pancas regarde ici au lancement. `version.json` (Windows) et `android.json` (Android) sont signés : Pancas refuse tout fichier dont la taille, l'empreinte ou la signature ne correspondent pas.
